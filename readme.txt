Animate text, images, sliders, galleries and buttons in Elementor, and build your own header and footer with display conditions. No coding required.

== Description ==

**MotionUI Addons for Elementor** adds professional animations, ready-made widgets and a Theme Builder to the free version of Elementor. Everything is configured visually inside the Elementor editor.

🔗 **[Live Demo](https://motionuiaddons.com/)**

= 🧱 Theme Builder (new in 1.2.0) =

Design your site's **header** and **footer** with Elementor and choose exactly where they appear.

* Create a header or footer from **MotionUI Addons → Theme Builder → Add New Template**.
* Design it in the Elementor editor like any other page.
* When you publish, a **Display Conditions** popup lets you pick where it is used: **Entire Site**, **Archives**, or **Singular** pages — all posts, all pages, a custom post type, a category, an author, or one specific item.
* Add as many **Include** and **Exclude** rules as you need. The most specific template wins when several match.
* Reopen the popup any time from the Elementor save menu → **Display Conditions**.
* Works with the free version of Elementor.

= ✨ Widgets =

* **Button** and **Burger Button** – animated, character-split button effects.
* **Animated Slide** – clip-path transitions, thumbnail and dot pagination, touch/swipe and prev/next navigation.
* **Typing Heading Motion** – animated, typed headings.
* **Testimonial** – a carousel of customer quotes.
* **Image** and **Gallery** – image reveal effects and a masonry gallery with filtering.

= 🎬 Animations for any widget =

* **Text Animation** – fade-up, reveal, slide-in, scramble and wave. Animate by characters, words or lines, with control over duration, delay, stagger and easing.
* **Image Animation** – directional, grid and column reveals.
* **Scroll Animations** – move, rotate, scale, skew and fade elements as they enter the viewport, or tied to scroll position.
* **Motion Library** – ready-made animations and a custom animation builder.
* **Advance Position** and **Custom CSS** – extra layout and styling controls.

= 🌐 Site-wide effects =

* **Smooth Scroll** – eased, inertia-style scrolling.
* **Preloader** – a loading screen until the page has loaded.
* **Ajax Page Transition** – fade between pages when visitors follow internal links.

== Installation ==

1. Upload the `motionui-addons-for-elementor` folder to the `/wp-content/plugins/` directory, or install it through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** screen.
3. Make sure **Elementor** is installed and activated.
4. Go to **MotionUI Addons** in your dashboard to choose which widgets, extensions and effects are enabled.
5. Open any page in Elementor and find the MotionUI widgets in the widget panel.
6. To build a header or footer, go to **MotionUI Addons → Theme Builder** and click **Add New Template**.

== Frequently Asked Questions ==

= Does this plugin require Elementor Pro? =

No. MotionUI Addons works with the free version of Elementor, including the Theme Builder.

= How do I create a custom header or footer? =

Go to **MotionUI Addons → Theme Builder → Add New Template**, choose **Header** or **Footer**, give it a name and design it in Elementor. When you publish, choose where it should display in the **Display Conditions** popup.

= How do I show a header or footer on specific pages only? =

In the Display Conditions popup, choose **Singular** (or **Archives**), pick the kind of page, and either leave it on **All** or search for one specific item. Use **Exclude** rows to leave pages out.

= Can I change where a template shows after publishing? =

Yes. Open the template in Elementor and choose **Display Conditions** from the save menu.

= Will it replace my theme's header and footer? =

Only on the pages that match your conditions. Everywhere else, your theme's header and footer are used as before.

= Is this plugin free? =

Yes. The features described here are free. Some additional widgets are available in the Pro version.

= Will this slow down my website? =

No. Scripts and styles load only on pages where the widgets or effects are used.

= Does it work with any theme? =

It works with any WordPress theme that supports Elementor, including Hello Elementor, Astra, OceanWP and GeneratePress. For the Theme Builder, themes that follow standard `get_header()` / `get_footer()` conventions work best.
