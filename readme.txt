== Description ==

**MotionUI Addons for Elementor** supercharges your Elementor-powered website with professional-grade animations and interactive widgets. Design stunning motion experiences directly inside the Elementor editor — no coding required.

Whether you want silky-smooth text reveals, cinematic image transitions, scroll-triggered effects, or animated sliders, MotionUI Addons gives you full creative control from a simple, intuitive interface.

🔗 **[Live Demo](https://motionuiaddons.com/)** | 🌐 **[Author Website](https://themeic.com/)**

= ✨ Features =

**🔤 Text Animations**
Animate your headings and text with a variety of effects including fade-up, reveal, slide-in, scramble, and wave. Animate by characters, words, or lines with full control over duration, delay, stagger, and easing.

**🖼️ Image Animations**
Apply stunning entrance effects to images including directional reveals, grid reveals, column reveals, and clip-path transitions. Supports left-to-right, right-to-left, top-to-bottom, and bottom-to-top directions.

**🎞️ Animated Slider**
A fully custom animation-powered slider widget with smooth clip-path transitions, thumbnail pagination, dot pagination, touch/swipe support, and prev/next navigation.

**🖱️ Scroll Animations**
Trigger animations as elements enter the viewport. Control X/Y position, rotation, scale, skew, opacity, and more — all driven by scroll position or on-entry.

**🖼️ Gallery**
Display image galleries with a masonry layout powered by Isotope. Includes filter support and smooth layout transitions.

**🔘 Button Animations**
Eye-catching animated buttons with character-split reveal effects, built to complement your page's motion design.

= 🎯 Why MotionUI Addons? =

== Installation ==

1. Upload the `motionui-addons-for-elementor` folder to the `/wp-content/plugins/` directory, or install it directly through the WordPress Plugins screen.
2. Activate the plugin through the **Plugins** screen in WordPress.
3. Make sure **Elementor** is installed and activated.
4. Go to **MotionUI Addons** in your WordPress dashboard to manage which widgets and features are enabled.
5. Open any page or post in Elementor and find the MotionUI widgets in the widget panel.

== Frequently Asked Questions ==

= Does this plugin require Elementor Pro? =

No. MotionUI Addons works with the free version of Elementor.

= Is this plugin free? =

Yes, MotionUI Addons for Elementor is 100% free with no hidden charges or feature locks.

= Will this slow down my website? =

MotionUI Addons uses a lightweight custom animation engine bundled locally with your plugin. Scripts are only loaded on pages where the widgets are actually used, keeping your site fast and performant.

= Does it work with any Elementor theme? =

Yes, it is compatible with any WordPress theme that supports Elementor, including Hello Elementor, Astra, OceanWP, GeneratePress, and others.

== Third Party Libraries ==

This plugin bundles the following third-party libraries:

* **MotionUI Animation Engine** — Custom-built animation library, GPL-2.0-or-later
  Bundled locally in `assets/js/motionui-ani.js`

* **SplitType v0.3.4** — MIT License
  Used for splitting text into characters, words, and lines for animation.
  Source: https://github.com/lukePeavey/SplitType
  Bundled locally in `assets/js/split-type.min.js`

* **Isotope v3.0.6** — GPL-3.0 License
  Used for masonry gallery layout and filtering.
  Source: https://github.com/metafizzy/isotope
  Bundled locally in `assets/js/isotope.pkgd.min.js`
